# 영상팀 워크플로우 구조도

성남시청 사진우 주무관의 AI 영상 제작 워크플로우를 **토목 도면 형식**으로 정리한 인터랙티브 구조도입니다. 발표 때 전체도(원경)에서 단계별로 줌인하며 설명하는 용도로 만들었습니다. 내용은 **2026-11-13** 시점의 실제 작업 파일 기준입니다. 기본은 발표 모드(짧은 경로)이고, 상세 시트는 부록으로 분리했습니다.

- 화면으로 보기: `index.html`을 브라우저로 열기 (GitHub Pages 링크는 레포 About 참고)
- 글로 읽기: [`docs/STRUCTURE.md`](docs/STRUCTURE.md) — 화면의 모든 시트를 순서대로 옮긴 텍스트 버전 (`python3 tools/export_structure.py`로 자동 생성)

## 전체 구조

```
발표 경로 (기본)
전체도 → 01 기획 → 02 음악 → △1 음악에 맞춰 기획 수정 → 03 이미지
       → 04 영상화 (실제 참조 3장 · 프롬프트 세 줄 · 결과 프레임)
       → 05 후처리 → 05-1 화성 잉크 프레임(클립) → 05-4 빈 현수막에 글자(클립) → 06 편집

부록 (D 키) — 질문이 나오면 펼치는 자료
01 기획   : A 기획 순서와 확정 · B 스타일 바이블 · C 콘티 항목
02 음악   : A Suno 프롬프트 구조
03 이미지 : A 프롬프트 구조 · B 참조 규칙·검수 · C 모델 변경
04 영상화 : A 프롬프트 해부(실제 제출본) · B 검사→생성→검수 · C 반복 실수 검사 · D 모델·모드 변경
05 후처리 : A 후처리 구성 (+ 05-2 매돌이 · 05-3 푸드테크 사례 카드)
06 편집   : A 편집 규칙
00 공통   : A 위키 지도 · B 실패 → 경고
```

→ 만 누르면 발표 경로가 끝까지 이어지고 부록은 건너뜁니다. 주소 뒤에 `?full`을 붙이면 부록까지 이어서 넘깁니다.

## 조작

| 키 | 동작 |
|---|---|
| → · Space · PageDown | 다음 |
| ← · PageUp | 이전 |
| P | 발표 모드 ↔ 부록 포함 모드 (왼쪽 아래에 현재 모드 표시) |
| D | 부록으로 / 부록에서 누르면 전체도로 복귀 |
| V | 현재 사례 카드의 클립 다시 재생(소리 켜기) |
| Esc · 0 | 전체도 |
| 1–6 | 해당 단계 |
| F | 전체화면 |
| H | 하단 안내 숨김 |
| 클릭 | 시트로 줌인, 빈 곳 클릭은 전체도 |

## 용어

화면에는 한국어 이름을 먼저 쓰고 내부 식별자는 작게 적거나 뺐습니다. 아래는 원래 식별자와의 대응입니다.

| 용어 | 뜻 |
|---|---|
| 영상팀 / 레인 | Codex 세션을 단계(레인)마다 새로 띄워 일을 나누는 작업 체계. 레인 순서: director → music → planner → image_creator → image_qc → seedance → seedance_qc → package |
| 디렉터 | 사용자와 대화하며 승인·진행을 판단하는 메인 대화 (Claude Code 또는 Codex) |
| P0–P5 | 프리프로덕션 단계: 컨셉 · 스타일 바이블 · 콘티 · 이미지 · 선반 · 제작 |
| 잠금 / STALE | 단계 파일을 확정하는 것. 상류 파일이 바뀌면 하류 잠금이 무효(STALE)가 된다 |
| 생성 전 묶음 (선반, shelf) | 블록마다 제작 직전에 잠가 두는 프롬프트·참조·설정 묶음 |
| 블록 / 숏 | 블록 = Seedance 생성 1회(기본 15초), 숏 = 블록 안의 컷 |
| I2V / No-I2V | 시작 프레임 이미지를 영상으로 만드는 방식 / 시작 프레임 없이 참조만 붙여 생성하는 방식 |
| 화풍 고정 문장 / 인물 고정 설명 | style_block_en / identity_block_en — 모든 프롬프트에 원문 그대로 반복하는 문단 |
| 반복 실수 검사 (prompt_lint) | 사용자에게 거절된 문구 패턴 13개를 프롬프트에서 잡아내는 검사 |
| 지식 라우터 | 블록 속성으로 위키에서 필요한 섹션만 골라 넘기는 로컬 스크립트 |
| 교훈 장부 | 사용자 승인·거절에서 나온 규칙을 날짜와 함께 모은 위키 페이지 |
| 캡슐 | 대화가 압축·인계되기 전에 남기는 작업 요약 |

## 출처와 범위

- 각 시트 하단에 근거 파일을 적었습니다. 근거 파일은 작성자 로컬 환경(`~/.codex/skills`, `~/wiki`, Claude 메모리)에 있고 **이 레포에는 포함되지 않습니다**. 런타임 코드·규칙 일부는 공개 레포 [GnuDaSsa/video-team-workflow](https://github.com/GnuDaSsa/video-team-workflow)에 있습니다.
- 수치(메모리 62, 캡슐 147, 교훈 장부 34, 반복 실수 검사 규칙 13, 지식 카탈로그 33)는 2026-11-13에 실제 파일을 세었습니다. 하트 프롬프트 수집 경로는 11-13에 만들었고 아직 0건입니다. 화면에서는 이 수치 시트(00-C)를 뺐습니다.
- 05 후처리: 성남 푸드테크와 「솔로몬의 선택」은 실제 원본 클립과 최종본의 비교입니다. 화성과 매돌이는 원본이 로컬에 없어 **최종본에서 효과 직전 프레임과 효과 순간**을 나란히 놓았고, 화면에도 그렇게 표기했습니다.
- 04 영상화의 참조 3장·프롬프트 인용·결과 프레임(assets/vid)은 성남시 MV 첫 15초 블록의 실제 제출 자료입니다(Seedance 2.5 · 5숏). assets/clips는 최종본·원본에서 자른 2.5–4초 클립입니다.
- 02 음악 화면의 레포 이름은 실제 이름(naqashmunir21/awesome-suno-prompts)으로 표기했습니다.
